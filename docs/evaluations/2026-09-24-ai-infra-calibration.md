## 4. 三层判定：不要把语料标签直接当回答标签

### 4.1 语料是否能回答

25 题分为：22 道语料可回答、2 道指代不明需澄清、1 道提取文本未发现定义。原题集没有天然的 partial 问题，这不代表运行时不能出现 partial。

`corpus_answerability` 只说明整份绑定语料的情况。即使 q04 在书中可完整回答，本次只取回预填充证据，运行时也只能判 partial。

### 4.2 本次证据是否充分

审阅者只对**实际送入该阶段的完整片段**逐项核对必要事实，记录 supporting chunk ID 和原句，不能借助 gold 答案补全缺失信息。

- supported：所有核心子问题均有充分证据。
- partial：至少一个可独立回答的核心子问题有充分证据，但一个或多个其他核心子问题缺乏充分证据。
- insufficient：没有任何可独立回答的核心子问题获得充分证据。

“事实点”不自动等于“独立子问题”。例如 q08 只找出六层中的两层，不能因命中两项事实就称 partial；q15 只有定义片段也不等于完整支持该章总结。事实覆盖可以有分数，但整题充分度按 core_subquestions 判断。若后续要把枚举题改成多个独立子问题，必须先修订金标准版本，而非为了提高成绩临时拆分。

q23、q24 使用独立的 `clarify` 行为金标准，不将其新增为运行时充分度的第四个状态；当前分类 API 仍是三类。最终回复应指出缺少的对象信息，不填入猜测数字。q25 应说明当前资料未找到定义，不编造解释；不要求检索候选必须为空。

### 4.3 回答是否忠实于本次证据

- 对有支持的独立核心问题，答案应正确、充分、引用真正支持该结论的片段。
- partial 必须回答有支持部分，并清楚列出缺乏证据的核心问题；不能用模型常识偷偷补完。
- insufficient 不生成肯定事实；解释缺少的依据或请求澄清。不能把“本次未检出”说成“整本书绝不存在”。
- 页码正确、引用编号合法、回答长、包含术语，都不能替代上述判断。

## 6. 后续运行器需生成的三类指标

当前 v1 运行器仍按旧页码/术语评分，**不能直接加载 v2 JSON，也不能声称已产出下列指标**。

1. 检索：对 22 道语料可回答题，分别审阅向量池、词法池、融合选择和送入生成的证据。报告核心子问题覆盖率、整题完整证据率；每一路保留 chunk ID、页码、来源、rank、RRF、重排信息。不是简单 page-hit rate。
2. 充分度：以人工审阅实际候选证据所得的三类标签为金标准，输出混淆矩阵、各类 precision/recall 及样本量；单独列误放行和误拒答。某类无样本记 N/A，不记 0 或 100%。6 个受控用例另表。
3. 回答：人工核对有证据核心问题的完成率、无依据断言、引用支持率和缺失项披露；对 q23/q24 另报澄清行为，对 q25 另报拒绝编造。未生成、调用失败和未审阅要单列，不能默认为通过或混作拒答。

运行时“没有证据却误答”与“本来有充分证据却误拒”应分开统计。只有已确认本次证据充分的样本才进入误拒答率分母；检索漏掉语料证据另归检索失败。保留原始计数，不用一个总通过率掩盖问题。

小样本、同一本书、多个重复概念，不适合直接宣称广泛准确率，也不够确定通用相似度阈值。后续阈值如需调参，先确定开发/留出划分与版本，不能反复在同一题集调参后称独立验证。
