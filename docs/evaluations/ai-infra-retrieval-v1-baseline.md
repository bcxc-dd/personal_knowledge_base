## 高频漏召回修复

本轮首先确认 q04、q08、q11 的共同根因：英文短语和大写缩写已参与词法检索，中文术语没有；同时本机重排器回退到向量排序，导致正确页要么无法进入候选，要么在最终证据窗口外。

- 查询构造：从中文问题中提取受控技术词（例如“预填充”“解码”“六层”“模型参数”），与英文技术词一起做精确候选检索；有中文术语时，要求至少两个术语匹配，抑制单个泛词带来的噪声。
- 证据选择：保护向量 Top-2，不让词法候选无条件替换最高相关的语义证据；其余位置按词法检索的覆盖顺序补充。
- 定义意图：对纯“什么是 X / X 是什么”问题，优先保留含“X 是 / 指 / 称”的定义句，避免封面或目录中的同名词干扰；同时跳过含“为什么/如何”的多部分问题，避免把机制问题误判成单一定义问题。

这些规则使 q04、q08、q11 分别命中第 14、13、11 页，并在同一份 20 题自动集上达到 20/20。对应回归测试覆盖中文术语候选、向量 Top-2 保护、定义句优先级与多部分问题的例外。

## 仍独立存在的资料不足问题

`q23`、`q24` 和 `q25` 不证明资料中存在答案。它们表明当前检索没有相关性阈值，任何问题都会返回最近片段。下一轮应独立校准“证据不足”判定：用真实问题集选择阈值、规定回答服务的拒答条件，并增加专门回归测试；不应为了让这三题通过而降低召回率。
