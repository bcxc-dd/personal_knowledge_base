# 资料不足：相关性阈值与拒答策略设计

## 目标

让个人知识库 RAG 只基于足以支持回答的资料作答：资料完全不足时不调用大模型；资料只支持问题的一部分时，只回答有证据的部分，并明确列出缺口。该策略不得降低现有 AI Infra 正例评测集的可回答性。

## 已确认的产品规则

- 完全无证据：返回“现有资料不足以回答”，不调用大模型生成正文。
- 部分支持：回答有引用支持的部分，并清楚列出资料未支持的部分；不得用常识补全。
- 充分支持：沿用现有回答与引用流程。
- 阈值通过正例、负例和真实问题校准，而不是凭单一向量分数设置。

## 架构

新增独立的证据充分度判定器（`evidence_assessor`）。它接收检索候选、最终证据、问题和检索诊断，返回：

- `supported`：证据充分。
- `partial`：存在可信证据，但未覆盖问题全部核心方面。
- `insufficient`：没有可信证据。

数据流为：`retrieve -> evidence_assessor -> answer`。检索召回、排序和最终证据选择不因判定结果而改变；判定器仅决定这些证据能否支撑回答，以及回答采用哪条分支。评测运行器复用同一判定器，避免线上与离线规则漂移。

## 判定信号

判定器组合以下信号：

1. 最高语义相关性：以最终证据的 `vector_similarity` 排除明显无关的近邻。
2. 词法支撑：受控技术词或缩写是否在候选中明确命中；沿用现有中文术语、多词匹配和英文缩写规则。
3. 证据一致性：多个独立片段是否共同支撑同一主题，降低单个偶然近邻带来的误答。
4. 重排状态：正常重排可作为辅助信号；回退为向量排序时，不将排名本身当作置信度。
5. 问题覆盖：从问题中抽取核心术语/短语作为覆盖项。命中全部或足够多的项为 `supported`，仅命中部分为 `partial`，未命中任何可支持项为 `insufficient`。

单一相似度阈值不作为决策依据；它只作为组合判定的一项保守门槛。

## 回答契约

- `supported`：将当前最终证据传给大模型，使用正常提示词和引用校验。
- `partial`：将可信证据传给大模型；提示词要求先回答证据覆盖的部分，再使用“资料未支持的部分”小节逐条说明缺口，且不得做无引用断言。
- `insufficient`：跳过模型调用，返回固定拒答文本、判定原因与空引用集；仍返回检索诊断，以便用户查看系统为何拒答。

回答事件和持久化消息中需要携带判定状态、原因和未覆盖项，以便前端呈现和历史回放。

## 配置与校准

将相关阈值作为设置项保存，并提供默认值。首次校准过程：

1. 记录 AI Infra 20 道自动正例与 3 道资料不足诊断题的判定信号。
2. 加入真实的完全无关和部分支持问题，防止仅对 q23-q25 过拟合。
3. 选择优先保护正例、同时拦截无关问题的保守阈值。
4. 将校准题、阈值和结果写入评测报告。

策略默认在校准验证通过后启用；设置界面应允许查看或调整阈值，但不暴露难以理解的内部细节作为必填操作。

## 前端呈现

- 充分支持：保持现有答案与来源显示。
- 部分支持：在回答中显示“资料未支持的部分”，并显示可用来源。
- 资料不足：突出显示拒答状态和简短原因；保留“检索分析”折叠面板，不将无关检索项作为答案来源。

## 评测与验收

评测报告新增三类指标：

- 正常题错误拒答率。
- 部分支持题处理正确率。
- 资料不足题拒答率。

必须覆盖的回归场景：完全无关问题、单条偶然近邻、部分支持的多部分问题、正常多部分问答、中文术语问答、缩写问答、重排器回退，以及空知识库。

验收条件：

- 现有 20 道 AI Infra 自动正例仍可回答。
- 资料不足题不会调用大模型，且不会返回无关来源作为答案证据。
- 部分支持题只陈述已被引用资料支持的内容，并明确指出未支持部分。
