# 知屿 · 个人知识库 MVP

用户上传资料后，系统自动解析、切分并生成向量；提问时从 **Chroma** 检索相关片段，再调用 **DeepSeek** 生成带引用的回答。

## 已实现

- 资料库、知识问答、资料详情、模型设置四个页面。
- TXT / Markdown / 文本 PDF / DOCX 上传；单份 20 MB、单次前端选择最多 20 份。
- 后台处理、状态轮询、同内容去重、失败重试、删除原文件和向量。
- 本地中文向量模型 `BAAI/bge-small-zh-v1.5`，首次使用下载约 90 MB，无需额外 Embedding API Key。
- 可独立配置兼容 `/embeddings` 的向量服务；默认 DeepSeek 回答服务，也支持其他 Chat Completions 兼容服务。
- 按知识库或指定资料提问、流式回答、停止生成、来源定位、历史会话与会话删除。
- 可选本地重排：先召回最多 20 个候选片段，再重排并选取最多 6 个证据；问答来源区可展开查看向量相似度、重排分数和回退状态。
- 回答可保存为独立的复习笔记；笔记支持编辑、删除和引用快照，仅用于阅读和复习，不参与检索或回答。
- SQLite / Chroma 持久化、重启恢复未完成任务、向量模型切换后的索引隔离。
- 按用户要求使用配置式 React Router，页面和组件保留独立 hooks / style 目录。

## 启动

环境：Windows、Python 3.10+、Node.js 22+。首次安装需要联网下载依赖和本地模型；不需要 PostgreSQL、Docker 或独立显卡。

```powershell
cd D:\rag
.\scripts\setup.ps1
.\scripts\start.ps1
```

访问 **http://127.0.0.1:8765**。如果依赖和构建已经存在，只需运行 `start.ps1`。前台运行时按 Ctrl+C 停止；不启动多个服务进程同时访问同一数据目录。

若 PowerShell 当前策略不允许脚本，可直接执行命令，不需要修改系统执行策略：

```powershell
.venv\Scripts\python.exe -m uvicorn app.main:create_app --factory --app-dir backend --host 127.0.0.1 --port 8765
```

开发前端时，在另一个终端执行 `npm run dev`，访问 `http://127.0.0.1:5173`。Vite 将 `/api` 转发到后端。修改正式前端后重新执行 `npm run build` 并刷新页面。

## 配置 DeepSeek

1. 打开「模型设置」。
2. 回答服务默认地址为 `https://api.deepseek.com`，默认模型 `deepseek-flash`，均可修改。
3. 在 API Key 输入框填入自己的密钥。留空保存时保留已有密钥；可单独删除已存密钥。
4. 向量模型保持「本地中文模型」。
5. 阅读内容发送范围并勾选允许，点击「保存配置」。
6. 上传一份资料，等待「可问答」后提问。首页可下载示例资料。

DeepSeek 当前公开接口和模型名参考：[官方接入说明](https://api-docs.deepseek.com/)。模型账号可用性与费用以服务商为准。本项目不会将 DeepSeek Key 用作向量服务 Key。

本地向量化不向外部模型发送正文。生成答案时，问题、少量历史对话和检索片段会发送到配置的回答服务；API 向量化则另会发送片段正文。密钥仅保存在本机后端 SQLite，读取配置时仅返回“是否已设置”。**本地数据库中的密钥未做静态加密**，应由操作系统账号及磁盘权限保护，备份同样需要保护。

## 处理与检索说明

原文件保存在 `data/files/`，文档状态、切分正文和会话在 `data/knowledge.sqlite3`，向量索引在 `data/chroma/`，本地模型缓存位于 `data/models/`。可用环境变量 `RAG_DATA_DIR` 更换数据目录。

为适应默认本地模型的输入窗口，当前按段落、PDF 页或 DOCX 表格定位，单片段最多约 400 字符，长段落之间保留约 60 字符重叠。这是字符切分，并非模型 token 精确预算。向量检索返回最多 6 个片段，模型接收片段和定位信息，回答中的引用编号校验后保存。

“有引用”不代表回答一定正确；仍需核对原文。验证版尚未加入重排、混合检索与经过评测校准的相似度阈值；资料无答案时依靠明确的依据约束提示模型说明不足，不承诺完全消除幻觉。

## MVP 边界

- 仅限个人本机使用，无账号认证；不要把监听地址改为公网地址。
- 不支持 OCR。PDF 某页没有可提取正文时，会指出页码并停止建索引，避免将部分遗漏当成完整成功；空白页也可能触发此检查。
- 复杂表格、公式、页眉页脚的解析质量需要人工核对；DOCX 表格单独提取，未复刻原版式。
- 尚未实现文件版本历史和原子替换。同名不同内容会提示冲突；更新资料请先删除旧版再上传，或明确改名以同时保留。
- 删除文档后不再检索它，但历史回答文字和已有备份仍可能包含其衍生内容。可另行删除会话；来源摘录在查询历史时对已删除文件隐藏。
- 重建索引期间该文件暂不参与新问答。重建不会删除原文件；切换 Embedding 后在设置页点击「重建所有索引」。
- 停止回答会取消上游聊天连接；已在运行的本地 CPU 向量计算可能在后台完成，但其结果不继续用于该次回答。
- 分类标签、独立关键词搜索、多设备、完整导出界面、pgvector 迁移均留待后续。

## 备份与恢复

1. 停止服务，确认没有另一个进程在处理同一目录。
2. 将整个 `data` 文件夹复制到另一个受保护目录。为节省空间，可不复制 `models`，恢复后会重新下载模型。
3. 恢复时同样先停止服务，保留当前目录的另一份备份，然后复制备份数据到目标数据目录，不合并不同时间点的数据库和索引。
4. 使用相同版本依赖启动，抽查原文件下载、文档状态、来源片段、历史会话和检索。若模型设置变化，重新建立索引。

备份包含密钥与私有文档，不上传到公开仓库。SQLite 文件与 Chroma 目录属于同一次停写备份。

## 验证

### AI-Infra 检索评测

评测集只覆盖本机的 `AI-Infra-Book.pdf`，用于检查学习概念时的证据召回。默认命令只运行本地检索，不会调用回答服务：

```powershell
.venv\Scripts\python.exe scripts\evaluate_retrieval.py
```

结果会写入 `test-results/ai-infra-retrieval-*.json`。报告中的 `failure_stage` 区分资料未解析、未召回、候选未进入最终证据，以及资料不足题却返回证据。

以下命令会为 25 道题调用当前配置的回答服务，可能产生费用；仅在需要人工填写回答清晰度和引用贴切度时使用：

```powershell
.venv\Scripts\python.exe scripts\evaluate_retrieval.py --with-answer
```

如果替换了 PDF，评测会因 SHA-256 不一致而停止。应先人工审阅新内容和预期页码，再有意识地更新评测集。

```powershell
.venv\Scripts\python.exe -m pytest -q
npm test
npm run build
```

后端测试使用真实 SQLite 和 Chroma，外部模型接口使用可控 HTTP 测试替身，不会调用付费服务。包含文件处理、范围过滤、删除、模型隔离、SSE、断连取消与密钥隐藏。当前 19 项后端测试、2 项前端测试通过，正式构建通过；测试依赖有两条弃用提示，不影响测试结果。

另已执行真实本地 Embedding、进程退出重启、停写备份恢复验证，以及浏览器示例上传、引用核对和真实 DeepSeek 问答：评审时间与负责人正确返回，预算未提供时明确说明资料不足。用户已有资料与配置保留。自动化本地恢复验证可运行 `.venv\Scripts\python.exe scripts\verify_local.py`，测试数据写到 `test-results/`，不访问用户的业务数据库。
